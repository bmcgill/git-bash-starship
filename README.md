# my custom config for the Starship prompt in Git Bash
*Display: current directory, git branch/status, NodeJS version, PHP version, time to process last command*

- install Starship prompt
- modify .bashrc in your user directory
- add config files to .starship in your user directory
- install JetBrainsMono Nerd Font
- in Windows Terminal, add a profile for Git Bash and set JetBrainsMono Nerd Font as the font face
